# Imagens e bibliotecas

As fotografias e a ilustração de retirada foram geradas para este projeto e são demonstrativas. Retratos de produtos não representam o catálogo real de uma confeitaria. O endereço apresentado é fictício.

- Three.js: biblioteca local em `vendor/three/`, licença MIT preservada em `vendor/three/LICENSE`.
- Cormorant Garamond: fonte local, licença SIL Open Font License em `assets/fonts/OFL-Cormorant.txt`.
- DM Sans: fonte local, licença SIL Open Font License em `assets/fonts/OFL-DM-Sans.txt`.

As licenças dos componentes de terceiros devem acompanhar suas respectivas cópias.
